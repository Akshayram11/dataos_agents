HOW TO USE THIS UI

From signal to action

  1. Scan the tenant.Every 60 seconds—or with Scan now—the observer reads DataOS APIs and applies health rules to all 16 allowed resource types.
  2. Build safe evidence.Only failed or stuck resources get bounded runtime, log and dependency evidence; Secret and IAM data stays hidden.
  3. Ask the agent.For a new incident, GPT-5.6 Luna receives the redacted evidence once and writes the cause, impact and safe next checks. Healthy scans use no LLM tokens.
